# Provider icon fixtures

Used only in deterministic native UI screenshots; these files are not installed
as hard-coded runtime logos. Runtime logos come from MA or gateway uploads.

- `provider-spotify.svg`: Music Assistant server `dev`,
  `music_assistant/providers/spotify/icon.svg`, blob
  `843cf994ae0ed3a11b257120798b17ceb6fb4a3f`.
- `provider-bbc_sounds.svg`: Music Assistant server `dev`,
  `music_assistant/providers/bbc_sounds/icon.svg`, blob
  `c91df7855092c3664dab6a4d5b7f92393b389779`.
- `provider-navidrome.png`: Navidrome `resources/logo-192x192.png`, blob
  `1fa2234e186b06aa955db4e764f57051cd73d43d`. Demonstrates a per-instance upload
  replacing the generic OpenSubsonic logo; it does not imply that all Subsonic
  providers are Navidrome.
