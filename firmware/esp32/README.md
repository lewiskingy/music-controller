# ESP32 firmware

Planned target: ESP-IDF + FreeRTOS + LVGL for Waveshare ESP32-S3 4.3-inch 800×480 touch LCD.

No firmware is implemented yet. Begin only after inspecting the actual board revision, display/touch BSP, PSRAM and battery/charging hardware.

Keep protocol/state logic separate from LVGL views and support OTA with rollback after initial hardware bring-up.
